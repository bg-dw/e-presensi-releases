# E-Presensi — Rilis

Repo ini menyimpan paket rilis **E-Presensi** (aplikasi presensi sekolah, Laravel)
untuk updater di dalam aplikasi.

- Updater memeriksa rilis terbaru di:
  `https://api.github.com/repos/bg-dw/e-presensi-releases/releases/latest`
- Setiap rilis berisi satu file `e-presensi-vX.Y.Z.zip`: kode aplikasi +
  `vendor/` + aset hasil build (`public/build`) + `version.json`.
- Kode sumber: https://github.com/bg-dw/e-presensi
